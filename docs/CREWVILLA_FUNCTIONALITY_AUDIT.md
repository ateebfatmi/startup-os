# CrewVilla Phase 1 functionality audit

Baseline revision `632a083` on `main`. This report includes the uncommitted stabilization changes. Stage is **local stabilization before a hosted pilot**.

## Verification boundaries

- Local demo tests use browser storage and same-origin browser channels. Playwright uses synthetic camera and microphone devices.
- Local PostgreSQL 18 exercises the application's actual SQL and policies with minimal Supabase-compatible Auth, Storage, and Realtime schema stubs. It does not exercise Supabase HTTP APIs, WebSocket admission, signed file URLs, or Auth email.
- No staging credentials were available in this workspace. Hosted authentication, role enforcement, cross-device collaboration, and external provider flows remain **BLOCKED BY EXTERNAL CONFIGURATION**. No migrations were applied to hosted data and no payment settings were changed.
- The inventory groups routes with their calling features. Source review identified findings and candidate risks. Full manual button-by-button, accessibility, mobile hardware, provider, and failure-injection coverage remains open.
